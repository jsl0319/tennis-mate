# Tennis Mate M2 UI·UX 구현 기준

> 상태: 구현 기준 · 2026-08-19
> 우선순위: M2 인증·프로필 구현에서는 이 문서가 이전 UI·UX 초안의 충돌 항목을 대체한다.

## 확정된 M2 입력 계약

| 항목 | 확정 구현 |
| --- | --- |
| 닉네임 | 앞뒤 공백 제거 후 2~12자, 한글·영문·숫자만 허용, 서버에서 유일성 검증 |
| 활동 지역 | 시·도 탭과 전국 시·군·구 검색으로 주 활동 지역 한 곳 선택 |
| 근처 지역 | `nearbyRegionAllowed` boolean으로 저장. 추가 지역 행은 만들지 않음 |
| 테니스 경험 | 3개월 미만 · 3~6개월 · 6개월~1년 · **1~2년** · 2년 이상 |
| 랠리·게임 경험 | 각각 하나 선택 |
| 원하는 플레이 | 1~2개 선택 |

## 화면 동작

1. 비로그인 사용자는 카카오 로그인 CTA만 볼 수 있다.
2. 최초 로그인 사용자는 카카오 표시명을 정리한 임시 닉네임을 제안받고, 닉네임을 서버에 확인·저장한다.
3. 온보딩은 지역, 경험, 랠리, 게임, 원하는 플레이의 5단계다.
4. 입력값은 `PUT /api/v1/me/tennis-profile` 하나의 트랜잭션으로 저장된다.
5. 프로필을 수정할 때는 `version`을 함께 보내 충돌을 감지한다.
6. 프로필 결과의 `추천 매치 보기`는 M3 전까지 안내 상태로 둔다.

## 구현 경계

- 전국 Region 데이터는 `prisma/region-data.ts`와 `npm run db:seed`로 관리한다.
- `src/features/profile/`에는 클라이언트 화면 상태만 둔다.
- 인증·현재 사용자 확인은 `src/auth.ts`, `src/server/auth/`에 둔다.
- 검증·프로필 저장 트랜잭션은 `src/server/domain/`에 둔다.
- Route Handler는 `src/app/api/v1/`에서 HTTP 입출력만 담당한다.

M3 추천 매칭, 매칭 등록, 신청과 활동 기능은 이 문서의 구현 범위가 아니다.
